Harnessing Edge AI and Robotics for life-saving search and rescue missions via autonomous navigation.

Watch Demonstration

Project Overview

The ML-Integrated Rescue Car is an advanced autonomous robotics project designed to assist in critical search and rescue operations. Using a high-definition stereo camera and LiDAR technology, the car can navigate through complex, debris-filled environments.

Integrated with machine learning models for real-time human detection and thermal sensing, it identifies survivors with remarkable precision. The dual-robot system allows for coordinated exploration.

Core Capabilities

  • TensorFlow Lite for Edge AI and Custom Stereo Vision Mapping
  • ROS (Robot Operating System) and Real-time LiDAR SLAM
  • Autonomous Obstacle Traversal
  • Live Thermal Victim Tracking & Multi-Robot Coordination
  • Remote Telemetry via LoRa frequencies
