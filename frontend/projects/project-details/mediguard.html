MediGuard – AI & IoT Based Smart Medicine Verification System

Reducing medication errors by verifying both the patient and the medicine before consumption using biometric and deep vision edge intelligence.

Project Summary

MediGuard is an intelligent healthcare system designed to reduce medication errors by verifying both the patient and the medicine before consumption. It combines fingerprint authentication with AI-based medicine image verification using an ESP32-S3 camera system. A dedicated Android application manages patient details, medicine enrollment, and medication schedules, while Firebase and a Flask backend provide cloud connectivity and data processing.

Project Overview

MediGuard consists of an ESP32-S3 based embedded device integrated with an OV3660 camera, AS608 fingerprint sensor, OLED display, and speaker. Patients are authenticated using their fingerprint, after which the system retrieves their scheduled medication.

The medicine is captured through the device camera and compared with previously enrolled reference images using a computer-vision pipeline based on image preprocessing, MobileNetV2 embeddings, and cosine similarity. The verification result is then communicated through the OLED and audio feedback. The Android application provides a centralized interface for patient registration, fingerprint enrollment, medicine enrollment, and schedule management.

Hardware Stack

  • ESP32-S3 N16R8 (Dual-Core AIoT SoC)
  • OV3660 Camera Module
  • AS608 Optical Fingerprint Sensor
  • 1.3-inch OLED Display
  • Speaker / Audio Module
  • Power Bank / Portable Power Supply

Software Stack

Arduino C++ / ESP32 Firmware Android Application (Java) Flask / Python Backend Firebase Firestore EasyOCR MobileNetV2 Cosine Similarity REST APIs Wi-Fi Communication

Implementation Result

A functional working prototype of MediGuard has been developed. The system successfully integrates fingerprint-based patient authentication, medicine reference-image enrollment, camera-based medicine verification, Firebase data management, and Android-based patient and schedule management. The ESP32-S3 communicates with the Flask backend over Wi-Fi, while verification results are displayed on the OLED and provided through audio feedback. The complete workflow—from patient authentication and medicine identification to verification and result generation—has been implemented and demonstrated.
