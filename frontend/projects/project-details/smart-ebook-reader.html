Arduino SSCS Challenge 2026

SMART AI Powered Study Guide and Ebook Reader

An ESP32-based multi-capability study companion combining offline eBook reading, FTP server, Bluetooth A2DP audio streaming, macro remote keypad, and Android AI assistant.

Summary

An ESP32-based EBook reader engineered to provide a distraction-free, screen-efficient learning experience with comprehensive peripheral and cloud connectivity:

  • eBook Reading & Storage: Read and store extensive eBook collections with up to 32GB SD card storage support.
  • FTP File Server: Functions as an active FTP server on the home network for wireless file management.
  • Bluetooth Audio Streaming: Store and stream ambient background study audio directly to external Bluetooth speakers.
  • Bluetooth Macro Keypad: Operates as a remote Bluetooth keypad to control smartphones or laptops.
  • AI Companion App: Dedicated Android companion app that parses study notes, generates AI flashcards, and syncs them automatically to the device.
  • SSCS Standards: Designed following the official Arduino SSCS Challenge 2026 guidelines.

Overview & Firmware Architecture

Core Firmware Libraries

  • Adafruit_SSD1306 & Adafruit_GFX (or U8g2): Drives the OLED display, performing low-level pixel manipulation, font rendering, line wrapping, and dynamic reader UI management.
  • SD.h / FS.h: Manages the FAT file system on the SD module to traverse directories, stream large .txt files into memory buffers, and store incoming notes.
  • ESP32-A2DP: Implements the Advanced Audio Distribution Profile (A2DP) source mode to stream I2S audio wirelessly to paired speakers.
  • BluetoothSerial.h: Manages Classic Bluetooth Serial Port Profile (SPP) connections for receiving raw note payloads over the air.
  • Keypad.h: Handles button matrix polling, hardware debouncing, and translation into navigational and media macro triggers.

Dual Data Pipeline Management

The ESP32 acts as a central hub managing concurrent display and wireless communication pipelines:

Display Pipeline: When reading, text chunks are fetched from the SD card into RAM, formatted by the graphics engine, and pushed to the SSD1306 OLED over I2C/SPI. Button polling triggers instantaneous text buffer paging.

Wireless Transfer & Audio: Audio macros invoke ESP32-A2DP audio encoding, while the BluetoothSerial SPP stream receives mobile text pushes and directly writes them to the SD card via the FS library—acting as a wireless flash drive.

Companion Android Application

Built completely in Android Studio with Kotlin and native toolchains, the mobile companion application inputs notes and documents in PDF format. It can either direct-port them to the IoT device over Bluetooth or leverage AI models to generate interactive study flashcards. The app also supports music file transmission and local summary archiving.
