Project Overview

The ML-Integrated Rescue Car is an advanced autonomous robotics project designed to assist in critical search and rescue operations. Using a high-definition stereo camera and LiDAR technology, the car can navigate through complex, debris-filled environments where human access is limited.

Integrated with machine learning models for real-time human detection and thermal sensing, it identifies survivors with remarkable precision. The dual-robot system allows for coordinated exploration, where 'Robot 1' acts as the primary scout unit, while 'Robot 2' serves as the specialized delivery and communication hub.
